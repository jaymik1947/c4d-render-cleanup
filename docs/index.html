Features

四个开关，别的一个没有

不做渲染管理，不做文件浏览器。只解决「渲染完这堆目录怎么办」。

文件夹名自己定

默认 mat 和 obj，每行一个，随时增删。精确匹配、不区分大小写。

总开关

取消勾选立即生效，后台守护下一次触发就停手，不用重启 C4D。

延迟可调

默认渲染结束后 4 秒动手，可以填小数。EXR 还在写就自动推迟重试。

进回收站，不是粉碎

走 Windows Shell API，删错能还原。检测到磁盘没有回收站就拒绝执行。

Install

两步装完

不需要装 Python、不需要 pip、不需要编译。

1

把 plugin 文件夹放进 C4D 插件目录

任选其一（推荐用户目录，升级 C4D 不会丢）：

# 用户目录（推荐） %APPDATA%\Maxon\Maxon Cinema 4D 2024_XXXX\plugins\ # 或者程序目录 <C4D 安装路径>\plugins\
2

重启 C4D，打开 扩展 → 渲染后删除文件夹

日志出现这一行就成功了：

插件注册：菜单=True 后台=True 版本=C4D 2024200 Python=3.11.4
How it works

为什么是双通道

C4D 的「渲染结束」没有可靠的公开事件，所以两条路一起走，谁先到算谁的。

通道 A 实测未触发

EVMSG_RAYTRACER_FINISHED —— SDK 私有事件。快，但在 R2024 + Redshift 下实测没发过。

通道 B 真正生效

1 秒心跳轮询渲染状态，检测 True → False 的落沿。稳，代价可忽略。

两条通道共用冷却时间，不会重复执行。
路径解析是唯一的坑：C4D 的 RDATA_PATH 存的是未解析的 token（比如 ...\test\$pass\$prj$res），插件会剥掉含 $ 的片段，再回退到最近一个真实存在的目录。
Config

配置都在界面上

设置面板写的是一份 JSON，也可以直接改文件。下面是全部字段。

字段默认说明
enabledtrue总开关
names["mat","obj"]要删除的文件夹名，精确匹配、忽略大小写
delay_ms4000渲染结束后延迟毫秒数
quiet_s3.0目录内文件多久没改动才算写完
cooldown_s10两次执行的冷却，防重复触发
roots["<render_output>"]扫描根目录，占位符取当前文档渲染设置
root_overridenull填绝对路径可跳过自动解析
min_depth3路径层级下限，太浅拒删
protect[]保护路径，命中即跳过
allow_networkfalse是否允许网络路径（那里没有回收站）
